# System Design Interview Guidelines

Interviewers should focus on:
- Clarifying requirements and estimating scale before designing.
- Data storage choices: SQL vs NoSQL, indexing, and caching (e.g. Redis).
- Async processing with queues or event streams (e.g. Kafka) and idempotency.
- Reliability: retries, timeouts, rate limiting, and graceful degradation.
- Observability: logging, metrics, and tracing in production.

Red flags: jumps straight to tools without understanding the requirements.

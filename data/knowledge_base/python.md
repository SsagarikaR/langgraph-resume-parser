# Python Interview Guidelines

Interviewers should focus on:
- Core language: mutability, generators/iterators, decorators, context managers.
- Type hints and data modelling (dataclasses, Pydantic, TypedDict).
- Concurrency: threading vs multiprocessing vs asyncio, and the GIL's impact.
- Testing with pytest: fixtures, mocking, and what makes code testable.
- Writing clean, idiomatic code over clever one-liners.

Red flags: cannot explain the difference between a list and a generator; no testing experience.
